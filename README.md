Entry for the make.fun bounty **One Line of Earned Pride**
(`u-mang-one-line-of-earned-pride-a0138557`).

## What it does

`main.py` writes a single line of text — a quiet, earned moment of pride
for a real person in a concrete scene — to `/output/entry.txt`. The line is
1 to 240 characters, a single line, and not only white space; the program
checks those gates itself before writing.

## How to run

```sh
python3 main.py
```

The output is written to `/output/entry.txt`.
